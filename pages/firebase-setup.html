Configuração Firebase

Integre seu banco de dados em nuvem em 3 passos simples

📋 Passo 1 — Criar Projeto no Firebase

1
Acesse console.firebase.google.com e clique em "Criar projeto". Dê o nome "executiva-pneus" (ou qualquer nome).
2
No menu lateral, vá em Criação → Firestore Database e clique em "Criar banco de dados". Escolha o modo Produção e selecione a região southamerica-east1 (São Paulo).
3
No menu lateral, clique em Autenticação → Primeiros passos, depois em E-mail/senha e ative. Crie um usuário em "Usuários" com seu email e senha.
4
Em Configurações do projeto (⚙️) → Geral → Seus aplicativos, clique em </> (Web), registre o app e copie o objeto firebaseConfig.
5
No arquivo assets/js/db.js, substitua os valores de firebaseConfig (apiKey, authDomain, projectId, etc.) pelos dados copiados.
6
Em Firestore Database → Regras, cole as regras abaixo para restringir acesso apenas a usuários logados e clique em Publicar:

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /{document=**} {
      allow read, write: if request.auth != null;
    }
  }
}

🔌 Passo 2 — Testar Conexão

Preencha suas credenciais de acesso para verificar se o Firebase está configurado corretamente.
